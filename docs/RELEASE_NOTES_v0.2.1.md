# Genome Evidence Audit v0.2.1

This release makes the annotation feature visible and easier to understand.

- Resistance, virulence, MLST, and species evidence categories are now displayed before analysis.
- The invented example includes all four categories, so researchers can see the grouped result cards immediately.
- The interface distinguishes current exact marker reporting from proposed automated interpretation.
- A GitHub-only implementation and validation plan documents species assignment, complete MLST, AMR, virulence genotype, and multi-genome transmission-compatibility reporting.

No clinical phenotype, disease severity, confirmed species identity, or direct transmission inference has been added. Those capabilities require the validation described in the plan.
