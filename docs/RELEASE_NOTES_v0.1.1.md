# Genome Evidence Audit browser edition v0.1.1

Public website: https://al-mualm.github.io/genome-evidence-audit/

The application is built as a static React application using Vite. This release moves the static application to GitHub Pages and removes the previous hosting integration and optional browser-assistant interface. The exact-sequence calculation core remains version 0.1.0 and is unchanged from the validated v0.1.0 release. The Python reference remains v0.2.0. No study results, matching rules, or interpretation thresholds change.

Validation: 16 engineering tests; TypeScript checking; production static build. Previous study parity evidence remains applicable to the byte-identical calculation core: 107 datasets and 733 marker transitions.
