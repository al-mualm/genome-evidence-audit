# طريقة الاستخدام

هذه واجهة للفحص المباشر قبل التنقية وبعدها، وليست التحليل الكامل لملفات FASTQ.

1. اختر الجينوم المجمع الأصلي بصيغة FASTA.
2. اختر ملف الأجزاء المتبقية بعد التنقية.
3. اختر ملف FASTA يحوي التسلسلات الدقيقة المراد تتبّعها، وليس أسماء الجينات فقط.
4. اضغط Run sequence audit.
5. راجع نتائج الاحتفاظ والفقد ومواقع التطابق، ثم نزّل التقرير.

زر Try an example يشغّل مثالاً مصنوعاً للشرح، ولا يعرض نتائج مرضى أو نتائج بيولوجية حقيقية.

تُعالَج الملفات داخل جهاز المستخدم ولا تُرفع إلى خادم. الموقع لا يجمع الجينوم من القراءات الخام ولا يعطي تشخيصاً أو توقعاً لمقاومة المضادات. فقد التسلسل أثناء المعالجة لا يثبت أن قرار الاستبعاد كان خطأ بيولوجياً.

المعاينة والمستودع أُعدّا بصورة خاصة أولاً. قبل وضع الرابط في البحث يجب إتاحة الإصدار للقرّاء وتثبيت رقم الإصدار وأرشفته، وإجراء اختبار استخدام على متصفحات مختلفة.
