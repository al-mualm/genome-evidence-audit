# طريقة الاستخدام

هذه واجهة للفحص المباشر قبل التنقية وبعدها، وليست التحليل الكامل لملفات FASTQ.

1. اختر الجينوم المجمع الأصلي بصيغة FASTA.
2. اختر ملف الأجزاء المتبقية بعد التنقية.
3. اختر ملف FASTA يحوي التسلسلات الدقيقة المراد تتبّعها، وليس أسماء الجينات فقط. ويمكن إضافة تصنيف للدليل داخل عنوان التسلسل، مثل `>blaKPC-2|category=resistance|trait=carbapenem`.
4. اضغط Run sequence audit.
5. راجع نتائج الاحتفاظ والفقد ومواقع التطابق، ثم نزّل التقرير.

زر Try an example يشغّل مثالاً مصنوعاً للشرح، ولا يعرض نتائج مرضى أو نتائج بيولوجية حقيقية.

تُعالَج الملفات داخل جهاز المستخدم ولا تُرفع إلى خادم. يستطيع الإصدار v0.2.1 عرض التطابقات المصنفة كأدلة مرتبطة بالمقاومة أو الضراوة أو MLST أو النوع. تظهر التصنيفات الأربعة قبل التحليل وفي المثال التعليمي، لكن التصنيف يأتي من ملف الباحث ولا يتحقق الموقع منه تلقائياً. وجود تسلسل مرتبط بالمقاومة لا يعادل نتيجة اختبار الحساسية، ووجود واسم نوعي لا يؤكد النوع، وتشابه الجينومات وحده لا يثبت انتقال العدوى.

الموقع لا يجمع الجينوم من القراءات الخام ولا يشغّل قاعدة بيانات جينية أو أداة تنميط كاملة. فقد التسلسل أثناء المعالجة لا يثبت أن قرار الاستبعاد كان خطأ بيولوجياً.

الموقع والكود متاحان للجمهور. الإصدار الحالي هو v0.2.1. هذا إصدار بحثي؛ تطابق الحسابات لا يثبت الدقة السريرية، ولم يُجرَ تقييم شامل لقابلية الاستخدام على متصفحات مختلفة.
